# 东方太极养生堂邀请函

- 公开邀请函：`index.html`
- 专属邀请链接生成器：`manage.html`
- 线上网址：<https://immort-magic.github.io/dongfang-taiji-invitation/>

## 专属链接

`manage.html` 在浏览器本机保存被邀请人名单，并生成包含 `guest`、`suffix` 和不可猜测 `invite` 参数的网址。名单不会提交到 GitHub。

## 自动赴约登记

- 邀请函通过 Cloudflare Pages Function 的 `/rsvp` 接口自动写入飞书多维表格，宾客无需打开或填写飞书表单。
- Worker 使用 D1 按邀请编号去重；同一专属链接重复点击不会新增重复记录。
- 飞书表格保持私有，网页没有读取记录的接口。
- 飞书表单只作为 Worker 的写入通道；表单登录会话由 Worker 临时创建，不在前端保存任何凭据。
- `worker/schema.sql` 是 D1 初始化脚本，`worker/src/index.js` 是接口实现；`pages-api/` 是面向中国网络发布的 Pages 部署入口。
